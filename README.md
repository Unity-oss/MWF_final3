Furniture Management System

A full-stack Furniture Management System designed to help furniture businesses manage inventory, sales, customers, orders, and operations efficiently.
Built to simplify furniture store workflows with a clean user experience and scalable backend architecture.

📌 Features
🪑 Inventory Management
Add, update, and delete furniture products
Track stock quantity and availability
Organize products by category
Upload product images
🛒 Order Management
Create and manage customer orders
Track order status
View order history
👥 Customer Management
Store customer details
Manage customer records
Track customer purchases
📊 Dashboard & Analytics
Overview of sales and inventory
Stock monitoring
Business insights and statistics
🔐 Authentication & Authorization

🚀 Installation & Setup
1️⃣ Clone the Repository
git clone https://github.com/your-username/furniture-management-system.git
cd furniture-management-system
2️⃣ Backend Setup
Create Virtual Environment
python -m venv venv
Activate Virtual Environment
Windows
venv\Scripts\activate
Linux/Mac
source venv/bin/activate
Install Dependencies
pip install -r requirements.txt
Run Migrations
python manage.py migrate
Start Backend Server
python manage.py runserver
3️⃣ Frontend Setup
cd frontend
npm install
npm start
⚙️ Environment Variables

Create a .env file in the backend directory and add:

SECRET_KEY=your_secret_key
DEBUG=True
DATABASE_URL=your_database_url
